# 模块 03 — 匿名树洞（Treehouse）

> 版本：v0.1 | 日期：2026-08-02

---

## 1. 模块概述

匿名树洞是 DevCave 最具差异化的功能之一，为程序员提供一个完全匿名的情绪出口。无论是深夜 debug 的崩溃感、被 deadline 追着跑的焦虑，还是对公司文化的吐槽，都可以在这里安全释放，不必担心职业影响。

**核心价值**：真实、安全、有共鸣——让程序员知道自己不是一个人在挣扎。

**设计原则**：
- 匿名永远优先，系统级别保证不可追溯（除极端紧急情况）
- 轻松氛围，避免沉重感；随机昵称带来趣味性
- 内容边界清晰，正向引导，不是抱怨大会

---

## 2. 用户故事

| ID | 角色 | 需求 | 验收标准 |
|----|------|------|---------|
| T-01 | 程序员 | 我想匿名发泄今天的崩溃情绪 | 发帖后显示随机匿名昵称，不关联主账号 |
| T-02 | 读者 | 我想找到有相同情绪的帖子 | 情绪筛选器有效过滤，结果准确 |
| T-03 | 程序员 | 我想匿名安慰别人 | 匿名回复流程顺畅，1步发送 |
| T-04 | 程序员 | 我想表达"我也是这样" | 共鸣按钮一键操作，计数实时更新 |
| T-05 | 楼主 | 我想标记哪条回复最有帮助 | "有帮助"标记可见，但不影响匿名性 |
| T-06 | 用户 | 我想举报违规内容 | 举报流程 2 步完成，后台人工审核 |

## 4. 匿名机制设计

### 4.1 匿名昵称生成规则

```
随机昵称格式：[形容词] + [名词/角色]
形容词库（示例）：燃尽的 / 快没电的 / 失眠的 / 摸鱼的 / 对齐失败的 /
                  迷路的 / 超时的 / 乱码的 / 死循环的 / 内存泄漏的
名词库（示例）：咖啡机 / 游戏手柄 / 调试器 / 像素 / 文件系统 /
               海豚 / 进程 / 端口 / 缓存 / 队列
```

**规则**：
- 同一用户每次发帖生成新昵称（不可手动选择）
- 不同帖子之间昵称无关联
- 同一帖子内楼主的所有回复使用同一个会话昵称（"楼主" 标识）
- 回复他人帖子时，生成当次回复专属匿名昵称

### 4.2 技术隔离方案（概念描述）

```
用户 ID → [单向哈希 + 随机 Salt] → 匿名发帖 Token
                                    ↓
                              帖子存储（仅含 Token，无用户 ID）

逆向查询路径（仅系统级访问）：
  紧急情况触发 → 需要 2 名管理员联合授权 → 临时解密 → 审计日志强制记录
```

### 4.3 审核触发规则

内容在以下情况自动进入人工审核队列：

| 触发条件 | 处理方式 |
|---------|---------|
| 包含"自伤"相关关键词 | 立即显示危机支持资源弹窗，异步人工审核 |
| 具名提及公司/个人并伴随负面描述 | 人工审核，72小时内处理 |
| 被举报 3 次以上 | 暂时隐藏，人工审核 |
| AI 分类为高风险内容 | 人工审核队列（v2.0 功能） |

## 5. 核心交互流程

### 5.1 发布树洞帖子

```
[点击"说点什么"悬浮按钮]
  ↓
[发帖抽屉出现（右滑入场，0.3s）]
  ↓
[选择情绪标签（必选，单选）]
  ↓
[输入内容（必填，20-500字）]
  ↓
[系统展示匿名昵称预览（可点击重新生成）]
  ↓
[点击"发布到树洞"] → [内容审核关键词过滤]
  ↓
  ├── 通过 → [发布成功，新帖出现在 Feed 顶部，Toast 提示]
  ├── 敏感词触发 → [弹出警示：建议修改]（不强制，用户确认后可继续）
  └── 高风险触发 → [弹出危机支持资源，帖子进入审核队列]
```

### 5.2 共鸣互动

```
[点击帖子卡片上的共鸣区域]
  ↓
  ├── 已登录 → [展开共鸣类型选择：😔共鸣 / 🤗加油 / 😊懂了]
  │           → [点击选择] → [计数 +1，图标高亮，0.2s 弹跳动效]
  └── 未登录 → [提示"登录后可以共鸣"]
```

### 5.3 举报流程

```
[点击"举报"]
  ↓
[弹出举报原因选择（单选）]
  包含：违规内容 / 人身攻击 / 泄露他人隐私 / 垃圾信息 / 其他
  ↓
[点击"提交举报"] → [后台记录，Toast: "已提交，感谢反馈"]
  ↓
[若累计举报 3 次] → [帖子进入人工审核，临时降低曝光]
```

## 6. 边界与约束

| 规则 | 说明 |
|------|------|
| 帖子长度 | 20-500 字符 |
| 回复长度 | 最多 200 字符 |
| 发帖频率 | 每用户每小时最多发布 3 条树洞 |
| 自动归档 | 超过 90 天的帖子移入归档（不可见但不删除） |
| 危机内容 | 检测到"自杀""结束生命"等关键词时，优先展示危机支持热线 |
| 数据导出 | 匿名内容不参与数据导出（保护匿名性） |
| 管理员权限 | 查询真实身份需双人授权 + 自动生成审计日志 |
| 禁止内容 | 具名攻击个人、泄露机密商业信息、色情、政治 |

## 7. 情感支持彩蛋设计

当用户选择"崩溃 💀" 情绪标签时，输入框下方悄悄出现一行小字：

```
💙 顺便提醒一下：你做到今天很不容易。休息一下也是可以的。
```

当用户发帖内容包含"辞职""裸辞"关键词（非违规，只是触发）时，发布成功后的 Toast 增加一句附加文字：

```
✓ 发布成功  |  "想清楚再做决定，你能撑到今天已经很厉害了。"
```
