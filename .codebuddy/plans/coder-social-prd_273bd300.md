## 用户需求

为程序员群体设计一款社交创意产品的完整产品设计文档（PRD + 原型描述），不涉及代码实现，输出可直接用于评审和研发启动的设计文档集。

## 产品概览

产品定位：程序员专属社交平台，融合技术分享、协作匹配、情绪释放、知识问答与活动组织五大场景，以极简高效的界面风格服务开发者日常需求。

**产品名称建议**：`DevCave`（开发者的洞穴/据点），呼应项目历史中"无码/孤独程序员"的文化基因。

## 核心功能

1. **技术分享与讨论**：支持 Markdown 编辑、代码片段语法高亮（多语言）、版本 Diff 对比展示；文章/片段可被评论、点赞、收藏、转发
2. **项目协作匹配**：填写技术栈标签与兴趣方向，系统推荐潜在队友；支持发布"寻找协作者"帖子，展示 GitHub/掘金影响力指标
3. **匿名树洞**：完全匿名发帖吐槽职业压力，支持情绪标签（愤怒/迷茫/焦虑等）、匿名回复，设有内容审核基准线
4. **技术问答积分体系**：提问→回答→采纳答案的轻量流程，积分驱动等级徽章，无复杂审核机制
5. **技术活动模块**：发布/报名线上线下活动，支持标签筛选（hackathon/读书会/分享会），展示参与者列表

## 技术栈

本任务为纯文档输出，无代码实现。所有产出物为 Markdown 格式文档，存放在项目仓库 `product-design/` 目录下，与现有 `pair-terminal` Rust 项目并列，相互独立。

## 实现方式

逐文件生成，先建立产品全局框架（README → PRD → IA → UI-SPEC），再逐模块深入描述原型细节。每个模块文档遵循统一模板：模块概述 → 用户故事 → 页面结构（按块描述）→ 核心交互流程 → 边界与约束。

## 文档规范约定

- 使用标准 Markdown，兼容 GitHub 渲染
- 信息架构图使用 Mermaid 语法绘制（嵌入 `.md` 文件）
- UI 规范使用表格 + 色值（HEX）描述，不依赖外部设计工具
- 页面原型以"线框描述法"呈现（分块列出区域名称、内容、交互），不生成图片文件

## 设计风格

**整体定位**：极简主义 + 深色优先的开发者美学，参考 VS Code、GitHub、Linear 的设计语言，拒绝花哨装饰，以内容和功能密度为核心，让程序员"一眼觉得舒服"。

**视觉基调**：深色背景 + 低饱和主色 + 高对比代码区域，配合精准的空白节奏，营造专注、高效的工具感。

## 页面规划（5 个核心页面）

### 1. 首页 / Feed 流（Home）

- **顶部导航栏**：产品 Logo（左）+ 全局搜索框（中）+ 通知/用户头像（右）；固定顶部，高度 56px，深色背景
- **左侧边导航**：图标 + 文字的竖向菜单，包含「发现」「匹配」「树洞」「问答」「活动」五个一级入口；宽度 220px，hover 高亮
- **主内容区（Feed）**：卡片式流布局，每张卡片含标题/代码预览/标签/作者信息/互动计数，卡片间距 12px，无阴影，用细线分割
- **右侧边栏**：「热门话题标签」+ 「推荐匹配用户」2 个小组件，固定宽 280px

### 2. 技术分享编辑器页（Editor）

- **工具栏**：Markdown 格式按钮（粗体/代码块/列表/链接）+ 语言选择下拉（代码高亮）+ 版本对比开关；紧贴顶部
- **双栏编辑区**：左侧 Markdown 原文编辑，右侧实时预览；分割线可拖拽调整宽度；代码块使用等宽字体 + 语法高亮主题（One Dark）
- **版本对比面板**：点击开关后从底部滑入，左右展示两个版本 Diff，删除行红色标记，新增行绿色标记
- **发布栏**：底部固定区域，包含「选择话题标签」「可见性（公开/私密）」「发布」按钮

### 3. 协作匹配页（Match）

- **个人技术档案卡**：页面顶部展示自己的技术栈标签云 + GitHub 贡献图（嵌入式）+ 掘金影响力分数，支持编辑
- **筛选栏**：技术栈多选标签 + 项目类型（开源/商业/学习）+ 在线状态过滤器
- **匹配推荐列表**：用户卡片网格（3列），每张卡片：头像 + 用户名 + 技术栈标签 + 匹配度进度条 + 「发起协作」按钮
- **我的协作请求**：底部分区，展示已发出/已收到的协作请求状态列表

### 4. 匿名树洞页（Treehouse）

- **顶部情绪筛选器**：横向滚动的 emoji 情绪标签（愤怒 / 迷茫 / 焦虑 / 崩溃 / 摸鱼 / 治愈），点击筛选
- **瀑布流帖子区**：双列瀑布流，每个帖子卡片含：情绪 emoji + 正文（最多 3 行截断）+ 匿名标识（随机昵称如「燃尽的咖啡机」）+ 回复数 + 共鸣数
- **发帖悬浮按钮**：右下角固定，点击弹出发帖抽屉（内含情绪选择 + 文本输入框 + 字数限制）
- **帖子详情抽屉**：从右侧滑入，展示完整帖子 + 匿名回复列表

### 5. 活动页（Events）

- **日历/列表视图切换**：顶部 Tab 切换，日历视图用月视图展示活动分布，列表视图展示卡片
- **活动卡片**：封面缩略图区 + 活动标题 + 时间/地点（线上/线下标识）+ 标签（hackathon/分享会）+ 已报名人数头像堆叠
- **筛选侧边抽屉**：类型/时间范围/城市/技术标签四维度筛选
- **发布活动按钮**：顶部右侧，触发多步骤表单（基本信息→活动详情→发布预览）

## 使用的 Agent 扩展

### Skill: frontend-design

- **Purpose**：生成产品原型的 UI 框架页面（React + shadcn），覆盖 5 个核心页面的可交互高保真原型描述
- **Expected outcome**：输出每个模块完整的页面组件结构描述和视觉规范，确保设计文档中的原型描述具有可直接落地的精度

### Skill: 腾讯文档

- **Purpose**：将生成的产品设计文档同步上传至腾讯文档云端，便于团队协作评审
- **Expected outcome**：在腾讯文档中创建「DevCave 产品设计」知识库空间，所有 `.md` 文件以在线文档形式可访问和评论
