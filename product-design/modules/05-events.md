# 模块 05 — 技术活动（Events）

> 版本：v0.1 | 日期：2026-08-02

---

## 1. 模块概述

技术活动模块是 DevCave 连接线上线下的桥梁，让开发者在代码之外找到真实的技术社群连接。无论是黑客松、技术读书会、分享会，还是小型 Workshop，都能在这里发现和参与。

**核心价值**：把屏幕后的程序员带到真实的社群中，或者让线上社群更有仪式感。

**模块定位**：轻量的活动聚合与组织工具，不追求与专业活动平台竞争，而是服务 DevCave 社区的内生活动需求。

---

## 2. 用户故事

| ID | 角色 | 需求 | 验收标准 |
|----|------|------|---------|
| E-01 | 社区组织者 | 我想发布一个 Hackathon 活动 | 填写基本信息后发布，出现在活动列表 |
| E-02 | 开发者 | 我想找附近的线下技术活动 | 城市筛选有效，展示线下活动地点 |
| E-03 | 开发者 | 我想报名参加一个活动 | 一键报名，成功后收到确认通知 |
| E-04 | 开发者 | 我想知道哪些朋友也参加了这个活动 | 参与者列表显示，关注用户头像优先展示 |
| E-05 | 组织者 | 我想查看我的活动报名情况 | 可查看报名人数和报名者列表 |
| E-06 | 开发者 | 我想用日历视图查看活动分布 | 月视图展示，有活动的日期高亮 |

## 4. 核心交互流程

### 4.1 报名活动流程

```
[浏览活动列表，点击感兴趣的活动]
  ↓
[查看活动详情，确认时间/地点/要求]
  ↓
[点击"立即报名"]
  ↓
  ├── 已登录 → [确认弹窗: "确认报名《活动名》？"]
  │           → [点击确认] → [报名成功]
  │           → [Toast: "报名成功！活动临近时将收到提醒"]
  │           → [按钮变为"已报名 ✓"，计数 +1]
  │           → [用户头像出现在参与者列表]
  └── 未登录 → [跳转登录，登录后返回原页面，自动触发报名]
```

### 4.2 发布活动流程

```
[点击"发布活动 +"按钮]
  ↓
[多步骤表单：基本信息 → 详情描述 → 预览发布]
  ↓
[每步均有校验，不通过不可进入下一步]
  ↓
[预览页确认]
  ↓
[点击"发布活动"] → [审核（自动关键词过滤 + 规则校验）]
  ↓
  ├── 通过 → [发布成功] → [跳转活动详情页]
  │         → [Toast: "活动已发布，开始接受报名"]
  └── 触发审核 → [暂存审核队列，48小时内人工审核]
               → [Toast: "活动已提交审核，将在 48 小时内处理"]
```

### 4.3 活动提醒规则

```
活动发布后：
  系统自动创建提醒任务：
    - 活动开始前 24 小时：站内通知 + 可选邮件通知
    - 活动开始前 1 小时：站内通知

用户报名后：
  - 立即：报名确认通知
  - 活动开始前 1 天：提醒通知
  - 活动开始前 30 分钟：最终提醒（如有线上链接则附带）
```

## 5. 筛选维度设计

| 筛选维度 | 选项 | 说明 |
|---------|------|------|
| 活动类型 | Hackathon / 分享会 / 读书会 / Workshop / 其他 | 多选 |
| 活动形式 | 线上 / 线下 / 混合 | 多选 |
| 时间范围 | 今天 / 本周 / 本月 / 自定义 | 单选 |
| 城市 | 北京 / 上海 / 深圳 / 杭州 / 成都 / 其他城市 | 单选（线下才有效）|
| 技术标签 | 同问答模块的标签体系 | 多选 |
| 费用 | 免费 / 付费 | 单选 |
| 报名状态 | 报名中 / 已报满 / 已结束 | 多选 |

## 6. 边界与约束

| 规则 | 说明 |
|------|------|
| 发布资格 | Lv.2（初级工程师）以上用户可发布活动 |
| 活动数量 | 每用户同时进行中的活动最多 3 个 |
| 修改限制 | 报名人数超过 50 人后，只能修改描述和联系方式，不能改时间/地点 |
| 取消活动 | 可以取消，但需要给报名者发通知 |
| 人数上限 | 最多 10,000 人（平台承载上限） |
| 封面图 | 必须是真实活动相关图片，不允许广告/营销图 |
| 活动有效期 | 活动结束后 7 天自动归档 |
| 重复报名 | 不允许（按钮变灰，显示"已报名"） |
| 取消报名 | 活动开始前 24 小时内可取消报名 |

## 7. 错误状态

| 场景 | 提示 |
|------|------|
| 活动已报满 | 按钮文字变为"已报满"（灰色，不可点击），页面显示"候补报名"按钮 |
| 报名截止 | 按钮变为"报名已截止" |
| 活动已取消 | 页面顶部 Banner 提示，并说明原因 |
| 发布等级不足 | Toast: "需要达到 Lv.2 才能发布活动" + [如何提升等级] 链接 |
| 描述为空 | inline 提示: "请填写活动详情，帮助大家了解这个活动" |
| 时间设置错误 | inline 提示: "结束时间必须晚于开始时间" |

---

## 8. 活动模块的内容审核标准

| 允许 | 不允许 |
|------|--------|
| 技术学习类活动（Hackathon/分享会） | 商业推广软广活动 |
| 开源项目相关活动 | 传销/非法集资相关 |
| 编程竞赛/技术交流 | 虚假活动（无法核实的线下地点）|
| 公益技术志愿活动 | 色情/违法内容相关 |
