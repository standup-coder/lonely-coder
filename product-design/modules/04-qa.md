# 模块 04 — 技术问答（Q&A）

> 版本：v0.1 | 日期：2026-08-02

---

## 1. 模块概述

技术问答模块是 DevCave 的知识沉淀入口，比 Stack Overflow 更轻量、更友好。没有严格的格式审核，没有高冷的"关闭原因"，只有提问→回答→采纳的简单闭环，配合积分激励，让愿意分享知识的人获得正向反馈。

**核心价值**：人人能问，人人能答，好答案被留住。

**与 SO 的关键差异**：
- 无复杂的问题关闭审核机制
- 评论区氛围更友好（有社区行为规范但不高压）
- 问题不必是"完美的技术问题"，也可以是"求推荐"类
- 积分体系与社区等级可见，激励更直接

---

## 2. 用户故事

| ID | 角色 | 需求 | 验收标准 |
|----|------|------|---------|
| Q-01 | 开发者 | 我想提一个关于 Rust 生命周期的问题 | 支持代码块，标签分类，提交后立即可见 |
| Q-02 | 开发者 | 我想回答一个我熟悉的问题 | 回答支持 Markdown，提交后实时显示 |
| Q-03 | 提问者 | 我想标记最好的答案 | 采纳答案后题目显示"已解决"标记 |
| Q-04 | 答题者 | 我想知道我的积分变化 | 积分变化实时通知，积分历史可查 |
| Q-05 | 浏览者 | 我想搜索特定技术的问答 | 关键词 + 标签双重过滤，结果相关 |
| Q-06 | 开发者 | 我想对一个好答案点赞 | 点赞成功，计数更新，回答者积分 +2 |

## 4. 核心交互流程

### 4.1 提问流程

```
[点击"提问 +"按钮]
  ↓
[进入提问页，标题 focus]
  ↓
[输入标题时，实时搜索相似问题（去重引导）]
  ↓
[填写详细描述（支持代码块）]
  ↓
[添加标签（至少 1 个）]
  ↓
[点击"发布问题"] → [校验：标题 20-150字，描述 > 30字，至少 1 个标签]
  ↓
  ├── 通过 → [发布成功] → [跳转到问题详情页] → [Toast: "问题已发布，等待高手解答"]
  └── 失败 → [错误高亮提示]
```

### 4.2 采纳答案流程

```
[提问者查看答案列表]
  ↓
[点击某条答案下的"采纳答案"按钮]
  ↓
[二次确认弹窗："确认将此答案设为最佳解？（采纳后可取消）"]
  ↓
[确认] → [问题标记为"✅ 已解决"]
       → [采纳答案置顶]
       → [回答者积分 +15，Toast 通知]
       → [提问者积分 +5]
```

### 4.3 搜索流程

```
[点击搜索框或按快捷键 /]
  ↓
[输入关键词，实时展示搜索建议（标题匹配）]
  ↓
[按 Enter 进入搜索结果页 /qa/search?q=xxx]
  ↓
[结果按相关性排序，支持标签过滤、时间过滤]
  ↓
[点击问题进入详情页]
```

## 5. 积分规则详表

| 行为 | 积分 | 频率限制 |
|------|------|---------|
| 每日首次登录 | +1 | 每天 1 次 |
| 发布问题 | +0 | 无限制 |
| 回答被采纳 | +15 | 每条答案 1 次 |
| 问题被采纳（提问者奖励） | +5 | 每条问题 1 次 |
| 回答被点赞 | +2 | 每次点赞 |
| 问题被收藏 | +1 | 每次收藏 |
| 文章被收藏 | +3 | 每次收藏 |
| 举报有效（被删内容） | +5 | 每次 |
| 违规内容被删除 | -10 | 每次 |
| 撤回采纳答案 | -5（回答者）-3（提问者） | 每次 |

**上限保护**：
- 同一天内，来自同一用户的点赞最多累积 +10 分（防刷积分互助）
- 积分不可负数（最低为 0）

## 6. 边界与约束

| 规则 | 说明 |
|------|------|
| 标题长度 | 20-150 字符 |
| 描述最短 | 30 字符（防止无效提问） |
| 标签要求 | 至少 1 个，最多 5 个 |
| 回答长度 | 30-20,000 字符 |
| 采纳答案 | 发布 15 分钟后才可采纳（防止自问自答刷积分） |
| 采纳撤回 | 可撤回，但有积分惩罚 |
| 问题关闭 | Lv.3+ 用户可投票关闭重复问题（需 3 票），关闭后重定向到原始问题 |
| 删除问题 | 有答案的问题不可删除（只能由管理员处理） |
| 编辑历史 | 问题和回答的编辑记录可见（防止悄悄修改问题让答案失效） |

## 7. 错误状态

| 场景 | 提示 |
|------|------|
| 标题过短 | "标题太短了，尝试更具体地描述你的问题" |
| 无标签发布 | "请至少添加一个相关标签" |
| 搜索无结果 | "没有找到相关问题，你来提第一个？" + [提问] 按钮 |
| 采纳自己回答 | "不能采纳自己的回答" |
| 积分不足特权 | 行内提示当前等级不支持该操作，显示所需等级 |
