# PRD — DevCave 产品需求文档

> 版本：v0.1 | 状态：概念稿 | 日期：2026-08-02

---

## 1. 背景与目标

### 1.1 问题陈述

现有程序员社区（掘金、SegmentFault、V2EX、GitHub Discussions）各有侧重，但没有一款产品同时满足以下需求：

- **即时技术分享**（有代码高亮、版本 Diff，但比博客轻量）
- **精准协作匹配**（基于真实技术栈，不是简历投递）
- **安全的情绪出口**（完全匿名，无需担心职业影响）
- **轻量问答激励**（有积分，但不像 SO 那么严苛）
- **技术活动聚合**（线上线下统一入口）

### 1.2 产品目标

| 目标 | 衡量指标（参考） |
|------|---------|
| 成为开发者日常打开的技术社区 | DAU/MAU ≥ 30% |
| 有效促成协作匹配 | 匹配率（双向接受）≥ 15% |
| 建立活跃的匿名情感社区 | 树洞帖子回复率 ≥ 40% |
| 形成可持续的知识沉淀 | 问答采纳率 ≥ 35% |

### 1.3 版本范围

本文档描述 **v1.0 MVP** 范围，聚焦核心功能骨架，每个模块实现基础闭环流程。

## 2. 目标用户

### 2.1 用户画像

**主要用户：在职软件开发者（25-35岁）**

| 属性 | 描述 |
|------|------|
| 职业 | 前端/后端/全栈/移动端/算法/DevOps 工程师 |
| 经验 | 1-10年工作经验 |
| 痛点 | 技术孤独感、找不到合适的协作者、无处倾诉职业压力 |
| 习惯 | 日常使用 GitHub、VS Code、Terminal；浏览掘金/知乎 |
| 期望 | 一个「懂我」的技术社区，界面不像普通社交软件 |

**次要用户：在校计算机专业学生（20-24岁）**

| 属性 | 描述 |
|------|------|
| 特征 | 活跃学习，参与开源，寻找实习/协作机会 |
| 需求 | 找项目队友、参与技术活动、学习问答 |

### 2.2 用户旅程（核心场景）

**场景 A：深夜 bug 后的吐槽**
> 凌晨 2 点，后端工程师小王刚把一个排查 3 小时的 bug 修好，打开 DevCave 树洞，选择"崩溃"情绪，匿名发出一句"又是 null pointer，我快疯了"，收到 47 个共鸣和 3 条匿名安慰回复，感到被理解，安心入睡。

**场景 B：寻找 Side Project 队友**
> 前端工程师小李有个想做的 SaaS 想法，但缺后端和设计。她在 DevCave 发布"协作寻人"，系统根据她的 GitHub 贡献图和技术栈（React/TypeScript）推荐了 3 个匹配度 80%+ 的后端开发者，2 天内找到了队友。

**场景 C：分享一段有趣的代码技巧**
> 资深开发者老张发现了一个用 Proxy 实现响应式的优雅写法，在 DevCave 分享了带语法高亮的代码片段和解释，24 小时内获得 120 次收藏和 15 条技术讨论回复。

## 3. 功能需求

### 3.1 模块总览

```
优先级 P0（MVP必须）：
  - 用户注册/登录（GitHub OAuth 优先）
  - 技术分享：发布/浏览/评论/点赞
  - 匿名树洞：发帖/匿名回复/情绪标签
  - 基础导航框架

优先级 P1（v1.0完整）：
  - 技术问答：提问/回答/采纳/积分
  - 协作匹配：技术档案/推荐列表/协作请求
  - 活动模块：发布/报名/列表展示

优先级 P2（后续迭代）：
  - GitHub/掘金数据接入
  - 代码 Diff 对比功能
  - 活动日历视图
  - 消息通知系统
```

### 3.2 用户账户系统

#### 3.2.1 注册与登录

| 功能 | 描述 | 优先级 |
|------|------|--------|
| GitHub OAuth 登录 | 一键授权，导入基础信息 | P0 |
| 邮箱注册/登录 | 备用方式 | P0 |
| 匿名身份分离 | 树洞模块使用系统生成的匿名昵称，与主账号完全隔离 | P0 |

#### 3.2.2 个人主页

| 区域 | 内容 |
|------|------|
| 基础信息 | 头像、用户名、一句话介绍、所在城市 |
| 技术档案 | 技术栈标签（最多 10 个）、工作年限、主攻方向 |
| 影响力展示 | GitHub 贡献图（通过 API 嵌入）、掘金影响力分（手动输入或 API）、DevCave 积分 |
| 内容统计 | 发布文章数、问答回答数、参与活动数 |

### 3.3 技术分享模块

> 详细原型见 [modules/01-share.md](./modules/01-share.md)

#### 核心功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| Markdown 编辑器 | 支持完整 Markdown 语法 + 实时预览 | P0 |
| 代码块高亮 | 支持 50+ 编程语言，主题 One Dark | P0 |
| 发布文章/代码片段 | 两种内容类型，片段更轻量 | P0 |
| 话题标签 | 最多 5 个标签，支持自定义 | P0 |
| 评论/点赞/收藏 | 三种基础互动 | P0 |
| 版本 Diff 对比 | 两个版本的代码或文本 Diff 展示 | P1 |
| 转发 | 转发到自己的主页，可添加评论 | P1 |
| 草稿保存 | 自动保存草稿，本地 + 云端 | P1 |

#### 内容类型定义

| 类型 | 字段 | 限制 |
|------|------|------|
| 文章 | 标题 + 正文（Markdown）+ 封面图 + 标签 | 正文最多 50,000 字符 |
| 代码片段 | 标题 + 代码块（含语言标记）+ 说明文字 + 标签 | 代码最多 10,000 行 |

#### Feed 流规则

- 默认展示：关注用户的内容 + 推荐内容（各 50%）
- 排序算法：发布时间 × 互动权重（收藏 > 评论 > 点赞）
- 分页：每次加载 20 条，下滑加载更多

### 3.4 协作匹配模块

> 详细原型见 [modules/02-match.md](./modules/02-match.md)

#### 核心功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 技术档案编辑 | 技术栈标签、项目经历关键词、寻找类型 | P1 |
| 队友推荐列表 | 基于技术栈 Jaccard 相似度 + 互补性评分 | P1 |
| 发起协作请求 | 发送消息模板 + 项目简介 | P1 |
| 接受/拒绝请求 | 通知提醒，双向确认 | P1 |
| 寻人帖子 | 公开发布"寻找协作者"帖，展示在 Feed 流 | P1 |
| GitHub 数据展示 | 贡献图、语言分布、Star 数 | P2 |

#### 匹配算法（概念描述）

```
匹配分 = 技术栈重叠度（Jaccard）× 0.5
       + 技能互补度（对方有我没有的技能）× 0.3
       + 项目类型偏好匹配 × 0.2

Jaccard(A, B) = |A ∩ B| / |A ∪ B|
```

### 3.5 匿名树洞模块

> 详细原型见 [modules/03-treehouse.md](./modules/03-treehouse.md)

#### 核心功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 匿名发帖 | 系统生成随机昵称（如「燃尽的咖啡机」），不可追溯 | P0 |
| 情绪标签 | 愤怒 / 迷茫 / 焦虑 / 崩溃 / 摸鱼 / 治愈（6种） | P0 |
| 匿名回复 | 回复者同样匿名，楼主可标记"有帮助" | P0 |
| 共鸣按钮 | 类似 GitHub reactions，多个情绪选项 | P0 |
| 内容审核 | 关键词过滤 + 举报机制，防止真实伤害内容 | P0 |

#### 匿名机制说明

- 用户登录状态下进入树洞，系统为当前会话分配随机匿名身份
- 同一用户的不同帖子使用不同匿名昵称（无法关联）
- 管理员在紧急情况（自伤相关内容）下可通过内部工具查询真实身份，但严格限制使用

#### 内容边界

| 允许 | 不允许 |
|------|--------|
| 职业压力、工作吐槽、公司文化批评（不具名）| 具名攻击特定个人 |
| 技术焦虑、职业迷茫 | 传播真实机密信息 |
| 情感宣泄、求安慰 | 自伤/鼓励自伤相关内容 |
| 正向调侃"摸鱼" | 违法违规内容 |

## 4. 非功能需求

### 4.1 性能

| 指标 | 目标值 |
|------|--------|
| 首屏加载时间 | < 2s（中等网络） |
| Feed 流刷新延迟 | < 500ms |
| 搜索响应时间 | < 300ms |
| 匿名发帖延迟 | < 200ms（用户无感知处理） |

### 4.2 安全性

| 要求 | 说明 |
|------|------|
| 匿名隔离 | 技术层面确保匿名帖不可反向追踪（除紧急情况） |
| HTTPS 全站 | 所有接口强制 HTTPS |
| OAuth 令牌安全 | GitHub Token 不落盘，仅用于数据拉取 |
| 内容审核 | 关键词实时过滤 + 人工审核队列 |
| 频率限制 | 所有写操作限速，防 spam |

### 4.3 可访问性

- 支持键盘导航（Vim 风格快捷键为可选项）
- 代码块支持一键复制
- 图片添加 alt 文字
- 颜色对比度满足 WCAG AA 级标准

### 4.4 平台支持

| 平台 | 支持级别 |
|------|---------|
| Web（Chrome/Firefox/Safari 最新版） | 完全支持 |
| 移动端 Web（响应式） | 基础支持（读取优先） |
| PWA 离线缓存 | v2.0 规划 |
| 原生 App | 不在 v1.0 范围内 |

## 5. 竞品分析

| 产品 | 核心场景 | DevCave 差异点 |
|------|---------|--------------|
| 掘金 | 技术博客分享 | DevCave 增加协作匹配 + 匿名树洞 |
| Stack Overflow | 技术问答 | DevCave 积分体系更轻量，社区氛围更友好 |
| V2EX | 开发者讨论 | DevCave 界面更现代，代码支持更好 |
| GitHub | 代码协作 | DevCave 更偏社交，无需代码仓库 |
| Blind | 职场匿名社区 | DevCave 技术属性更强，非纯吐槽 |
